# Home Assistant add-ons

Personal Home Assistant add-ons. To install, add this repository's URL in Home Assistant (Settings > Add-ons > Add-on store > menu > Repositories).

| Add-on | Description |
|---|---|
| [Finance](finance/README.md) | Self-hosted personal finance tracker: Plaid transactions, passkey login, served through a Cloudflare Tunnel |

This repository is public. It holds code only: no personal data, account details, tokens, or configuration values.
